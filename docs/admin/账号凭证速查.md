### beta 的登录账号（真机验收用）

| 项 | 值 |
|---|---|
| 邮箱 | `beta-tester@euriskotax.com` |
| 口令 | `41cx2AIdLUDmMkSw` |
| 权益 | `plan=pro` |

**为什么必须现建、且建了要记下来**：beta 用的是独立库 `eurisko_beta`，与正式库不通
（实测 beta 库 `User` 表 0 行、正式库 3 行），所以**正式站的账号在 beta 登不进去**；
而 beta 的 `SMTP_PASS` 是刻意留空的（不向真实用户发测试邮件），所以**注册这条路在 beta
上也走不通**（收不到邮箱验证码）。要在 beta 真机验登录链路，只能在库里直接建号：

```powershell
scp -i ~/.ssh/euriskotax_sskkey.pem tools\ops\beta-ensure-test-user.sh ubuntu@101.42.89.184:/tmp/
ssh -i ~/.ssh/euriskotax_sskkey.pem ubuntu@101.42.89.184 'bash /tmp/beta-ensure-test-user.sh beta-tester@euriskotax.com <口令>'
```

脚本幂等：账号已存在就只重置密码（**不删号重建** —— 级联会带走该账号的计算记录与反馈）。
2026-10-24 已跑通：登录返回 200 且拿到 token。
- **口令忘了怎么办**：明文口令没落盘（Caddyfile 里只有 bcrypt 摘要），重设一次即可
  `scp tools/ops/beta-caddy-server.sh ubuntu@101.42.89.184:/tmp/ && ssh ... 'bash /tmp/beta-caddy-server.sh euriskotax-beta <新口令>'`
  （脚本幂等，会备份 Caddyfile、整块替换 site block、validate 后 reload）。

## 常用命令

```powershell
# 核对 beta（公网域名；口令也可存环境变量 BETA_AUTH_USER / BETA_AUTH_PASS）
powershell -File tools\ops\ops-check-beta.ps1 -AuthUser euriskotax-beta -AuthPass <口令>

# 发 beta
powershell -File tools\ops\ops-deploy-beta.ps1

# 正式站：部署 + 核对
powershell -File tools\ops\ops-deploy.ps1 -SkipTest
powershell -File tools\ops\ops-check-prod.ps1
```

## 排障

本机 `nslookup beta.euriskotax.com` 报不存在、但阿里 DNS（`nslookup beta.euriskotax.com 223.5.5.5`）
能解析时，是本地/运营商 DNS 的**负缓存**（在这个域名还没记录时查过一次的不存在结果）没过期：
先 `ipconfig /flushdns`；反复出现就把网卡 DNS 换成 `223.5.5.5` / `119.29.29.29`。
