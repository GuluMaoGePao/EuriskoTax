# 高商业意图 SEO 落地页（阶段14 剩余项）

*创建：2026-09-13 · 状态：前两页已随 v1.14.0 / v1.15.0 上线（年终奖个税、月薪个税），其余词条待办*

## 1. 为什么单独立项

阶段14（变现与可信度）随 v1.13.0 上线后，唯一剩下的待办就是这一项。它之所以一直挂着，不是因为难，而是因为**做法容易做错**：

- 主站是 SPA（`express.static` + 未命中路由兜底 `sendFile(index.html)`）。搜素引擎抓 `/` 只能拿到一个空壳 + 一堆脚本，正文靠 JS 渲染 —— 高商业意图词（「个税计算器」「年终奖个税」）在结果页里拿不到任何可索引的实质内容。
- 落地页最常见的两种死法：
  1. **页面没用**：纯营销文 + 「立即使用」按钮。用户搜「年终奖个税怎么算」点进来，看到一段话和一个按钮，直接返回。收录了也留不住，还可能被判低质。
  2. **页面抄了一份算法**：为了「能算」，把税率表或计税公式复制进 HTML。App 侧改了口径（或运营在后台热改了税率），落地页还是老数字 —— 同一个人在落地页与首页看到两个结果，信任直接归零。

本方案的全部设计都是为了避免这两种死法。

## 2. 设计原则（改动时必须遵守）

| # | 原则 | 落地方式 |
|---|---|---|
| 1 | 页面自己有用 | 每页自带一个能跑的最小计算器，而不是只有 CTA |
| 2 | 口径同源，不复制 | 税率表读 `window.bonusMonthlyTaxRates`（`tax-constants.js` 出厂值 + `tax-rates-sync.js` 从 `/api/config/tax-rates` 覆盖的热改值），与 App 同一份 |
| 3 | 计算逻辑可证明等价 | 轻量实现放 `src/js/calculation/bonus-tax-quick.js`，由 `tests/bonus-tax-quick.test.js` 与内核 `calculateBonusTax` 在六个临界点 ±1 元、档内采样、极值上**逐点对拍** |
| 4 | 正文静态可抓取 | 规则、税率表、临界点表、FAQ 全部是 HTML 正文，不依赖 JS；JS 只负责把用户输入变成结果 |
| 5 | 首屏零 CDN | 手写共享 `seo/landing.css`（约 4KB），不引 Tailwind / 图标字体，脚本 `defer` |
| 6 | 一页一词，互不重复 | 每页只瞄准一个意图词，标题/描述/H1/正文围绕同一个词，避免站内自相残杀 |
| 7 | 可归因 | 所有进 App 的链接带 `?source=seo_<page>`，服务端 `SOURCES` 白名单同步登记，能在管理台按来源看线索 |

## 4. 关键技术决定

- **不引入静态站点生成器**。落地页数少（个位数），手写 HTML + 共享 CSS 足够；引入构建链会让「改一个数字」变成「装依赖、跑构建」，与本站「无构建」的既有形态冲突。
- **不做 SSR 化的 SPA 首页**。改造主站渲染方式风险远大于收益；落地页承担可抓取内容，首页继续做交互应用，两者用 CTA 连接。
- **临界点表格由测试守护**。表格里的数字（如 36000 元多 1 元多缴 2310.10 元）不是手抄的，而是 `tests/bonus-tax-quick.test.js` 断言的对象 —— 数字改了测试就红。
- **静态表格要对账，不能靠「禁止出现数字」**。落地页为了「爬虫不执行 JS 也能读到税率表」，正文里必然有一份静态表格 —— 最初我写的断言是「页面不含 `15160`」，结果被自己的页面当场拦下（规则表本来就该有 15160）。正确做法是**逐档对账**：
  - `verify:local`：把页面正文里的税率/速算扣除数与 `tax-constants.js` 的七档逐一对照，常量改了页面没改就失败；
  - 单测：把页面正文的税率表、临界点表解析出来，与常量文件、内核计算结果逐一对照（`tests/bonus-tax-quick.test.js` 后四例）。
  这样页面可以为了可抓取而「呈现」数字，但不能「拥有」数字。
- **示例表与公式也进对拍**：月薪个税页的 12 个月逐月预扣表（首月 300 / 第 4 月 580 / 全年 9480）由 `tests/salary-tax-quick.test.js` 按同源计算逐行对账 —— 示例是「为可抓取而呈现的数字」，同样不能手抄。
- **累计额必须逐月相加，不能「单月额 × 月数」**：`2999.99 × 12 = 35999.88`，而逐月相加是 `35999.87999999999` —— 浮点下并不恒等。要与内核逐位一致，就得沿用内核的累加方式，否则对拍会出现「差 1 分钱」的假失败。
- **收录自洽由门禁守护**：robots 声明 sitemap、sitemap 收录首页与**全部**落地页（新页必须同时进 sitemap，否则门禁红）、**sitemap 里每一条 URL 都真的返回 200**。

## 6. 风险与合规

- **税务口径**：所有页面统一注明「本测算结果仅供参考，不构成税务建议；实际纳税请以税务部门核算为准」，并在页脚重复一次。
- **政策时效**：年终奖单独计税政策执行至 **2027-12-31**（财政部 税务总局公告 2023 年第 30 号）。到期前后必须复核页面正文与结构化数据。
- **ICP 备案**：站点目前部署在境外（Zeabur 域名），百度等国内搜索引擎的收录与排名会受备案与本地化因素影响。落地页在备案完成前后都能工作，但**自然流量收益要等备案 + 收录周期**，不要用它衡量短期转化。
- **不与主站重复内容**：落地页只写「规则 + 速算 + 跳转」，不复制首页标题与描述，canonical 指向自身而非首页。
