# EuriskoTax 故障排查 SOP 标准模板

> 文档版本：v1.0 | 创建日期：2026-08-10
> 模板类型：标准操作流程（SOP）模板
> 用途：当系统出现故障时，按本模板填写并归档，形成可复用的排查知识库

---

## 模板使用说明

1. **复制本文件**到 `docs/tech-reports/` 目录，命名为 `troubleshooting-<故障简称>-<YYYYMMDD>.md`
2. **按章节填写**，无法确定的项标注 `待补充`
3. **排查完成后**在 docs/README.md 的"故障排查档案"表格中登记一行
4. **归档原则**：只记录有复用价值的信息，一次性问题可简略

### 5.2 根本解决

<记录彻底解决问题的操作，如：>

```powershell
    -Direction Outbound -Action Allow `
    -Protocol TCP -RemotePort 587 `
    -Profile Any
```
