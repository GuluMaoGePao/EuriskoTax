## 0. 一页纸：本期定位与三条铁律

### 0.1 定位（2026-09-24 决策）

> **现阶段不做付费功能。** 站内不出现价格、购买、订阅、付费引导；**全部商业动作收敛为「留资」**，由客服接入私域完成咨询与交易，交易完成后由后端客服发放**升级码**，用户回站自助开通。

闭环：

```
SEO 21 页 / 分享图 / 自然搜索 / 口碑
        │  免登录、零门禁地算完（calc_done 北极星）
        ▼
  站内留资触点（结果页 · 我的页 · 额度提示 · 报告钩子）
        │  lead_submit
        ▼
  私域 1v1（企微 / 客服）：核对参数、讲方案、谈服务
        │  交易在站外完成（绕开 iOS 虚拟支付与小程序平台红线）
        ▼
  后端客服发放升级码（ProCode）
        │
        ▼
  用户回站「升级码」入口自助开通 → 权益生效（云同步 / 精装报告 / 额度）
```

### 0.2 文案三条铁律（不可越）

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | **站内只做两件事：算（零门禁）+ 留资（顾问协助）** | 计算过程一旦出现付费门禁，会同时伤 `calc_done` 与 SEO 口碑 |
| 2 | **不出现价格、购买按钮、「付费 / 订阅 / 开通套餐」营销语** | 与本期定位冲突；且小程序 / iOS 端展示即违规 |
| 3 | **升级码入口只承接「已经拿到码的人」** —— 不做权益对比、不做引导购买 | 它是交付末端，不是营销位；配一段「还没有码？留资由顾问协助」即可 |

### 0.3 合规三条底线（不可越）

| # | 底线 |
|---|---|
| 1 | **税务免责声明必须随结果出现** —— 结果区 / 分享图 / 报告 / 落地页页脚，一处都不能少 |
| 2 | **不得出现广告法极限词与绝对化承诺**（最 / 第一 / 唯一 / 权威 / 官方认证 / 有问必答 / 保证） |
| 3 | **未备案不展示备案号**；备案号下发后，主站与 21 个落地页**页脚必须同时具备**主体名 + ICP 号 + 公安号 + 免责声明 |

## 1. 怎么用这份文档（维护机制）

### 1.1 合规审核状态定义

| 标记 | 含义 | 处理方式 |
|---|---|---|
| ✅ **通过** | 用语统一、无风险词、符合备案口径 | 可直接使用，改动需同步本文 |
| 🟡 **待改** | 口径不一致 / 主观表述 / 承诺需对齐 | 按「规范文案」改写，上线前应处理 |
| 🔴 **必改** | 违反广告法 / 与本期定位冲突 / 缺法定展示项 | **上线前必须处理** |
| ⏳ **待生效** | 依赖备案号下发或 SLA 确认后才能展示 | 配置留空，条件满足后填值即可 |
| ⬜ **已废弃** | 定位调整后不再展示 | 删除文案与 DOM，不留空壳 |
| 🆕 **新增** | 现状缺失，需补 | 按规范文案新增 |

### 1.2 单一真源：所有通用文案只写一处

现状痛点：同一句免责声明在 `index.html` / `deep-wizard-ui.js` / `share-card.js` / `export-utils.js` / 21 个落地页里各写一遍，改一处漏一处（实测已有 8 种后缀写法）。

**落地方式**（不改变现有模块结构，只抽常量）：

```
src/js/copy/copy-standard.js        ← 新增：导出本文 §2 的全部通用文案常量
   ├─ DISCLAIMER.result      A 型（结果区整句）
   ├─ DISCLAIMER.short        B 型（短句 + 主管部门后缀枚举）
   ├─ DISCLAIMER.report       报告四条（与 final-report.js 现状一致）
   ├─ DISCLAIMER.expired      政策过期
   ├─ PRIVACY.local          本机计算
   ├─ LEAD.*                 留资链路文案
   └─ FILING.*               备案位文案
```

- `index.html` 的静态文案与 21 个落地页**无法引用 JS 常量**（静态 HTML + SEO 需要纯文本），因此这两处靠 **§7 的守护测试**兜住一致性，不靠自觉。
- `src/js/**` 渲染的文案**一律引用常量**，不再字面量硬编码。

### 1.3 改动流程（保证不影响整体一致性）

```
① 改本文规范条目（更新「规范文案」列 + 版本记录表）
        ↓
② 改 src/js/copy/copy-standard.js（若涉及通用文案）
        ↓
③ 改调用处；静态 HTML 用工具脚本批量替换（见 §7.2）
        ↓
④ 跑 npm test（含新增的 tests/copy-standard.test.js 守护断言）
        ↓
⑤ 视觉基线重拍（文案变化会影响 28 张基线）
```

### 2.3 免责声明：主句固定 + 后缀受控枚举（核心统一项）

**A 型 · 结果区整句**（结果页 / 向导结果步 / 报告首页）

> `测算结果依据您填写的数据与现行政策估算，仅供参考，不构成税务建议；正式申报请以主管税务机关核定为准。`

**B 型 · 短句 + 主管部门后缀**（分享图 / 落地页页脚 / 助手回答 / 卡片角标）

> 主句（固定，不得改字）：`本测算结果仅供参考，不构成税务建议；`
> 后缀（**只能从下表 5 选 1**，不得自造）：

| 后缀 | 适用页面 |
|---|---|
| `实际纳税请以主管税务机关认定为准。` | 默认；个税、增值税、企税、附加印花、各类所得 |
| `实际缴费与纳税请以当地社保、公积金经办机构与主管税务机关认定为准。` | 社保基数、企业用工成本、到手工资 |
| `实际纳税请以主管税务机关与年金计划受托人认定为准。` | 企业年金 |
| `实际应缴金额请以主管税务机关、残联与工会组织认定为准。` | 残保金与工会经费 |
| `实际纳税请以主管税务机关与商业银行认定为准。` | 个人养老金、税优健康险 |

**C 型 · 附加建议类**（涉及金融/保险/投资判断的页面，在 B 型后追加一句）

| 追加句 | 适用 |
|---|---|
| `本页不构成投资建议。` | 个人养老金 |
| `本页不构成保险产品购买建议。` | 税优健康险 |
| `本页不构成是否参加企业年金的建议。` | 企业年金 |

**D 型 · 政策过期**（徽标 + 结果区提示）

> `该政策已过有效期，测算结果仅供参考；请以最新政策与主管税务机关认定为准。`

**E 型 · 报告四条**（`final-report.js:179-182` 现状即标准，✅ 通过，不得改字）

## 3. 合规红线清单

### 3.1 广告法（极限词与绝对化用语）

| 风险词 | 判定 | 处置 |
|---|---|---|
| 最、第一、唯一、顶级、极品、首创、国家级、世界级、领先 | 用于**宣传本站服务** → 🔴 必改 | 删除或改为中性表述 |
| 最（描述性：最高税率、最长一项、最易填错） | 政策术语/描述，非宣传 | 🟡 建议改为「常见」「上限」等中性词 |

| 保证、100% 准确、绝对、永久有效 | 🔴 必改 | 改为「通常情况下」「以…认定为准」 |

| 免费 | 与本期「不做付费」定位冲突，且易被读作营销 | 🔴 站内促留资场景一律改 `顾问协助`；描述档位额度时保留（`免费版可保存 2 套`） |
