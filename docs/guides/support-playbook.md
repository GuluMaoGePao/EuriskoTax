# 客服排障手册（User Support Playbook）

> 面向客服 / 运营同学。目标：**先用最短步骤让用户恢复可用，再判断是不是产品缺陷。**
>
> 配套：管理台「排障」Tab（`admin.html` → `排障话术库`）内置了本手册全部话术，支持一键复制。

---

## 一、先记住这一个链接

```
【排障短链】https://euriskotax.zeabur.app/reset
```

它做三件事：注销本站 Service Worker → 清空离线缓存 → 自动跳回首页。

- **不影响**登录状态、计算历史、本地设置
- 用户**无需**懂任何技术，点开等它跳转即可
- 是绝大多数「看不到新版页面」问题的**第一处理手段**

> 部署到新域名时，短链随域名变化，管理台「排障话术库」里的 `{RESET_URL}` 会自动渲染为当前域名，直接复制即可。

---

## 二、处理顺序（三层）

| 层级 | 手段 | 适用 |
|---|---|---|
| L1 | 发排障短链 `/reset` | 页面异常、功能没更新、按钮点不动（绝大多数） |
| L2 | 无痕窗口 / 换浏览器 | 短链无效，或怀疑浏览器扩展干扰 |
| L3 | 升级为产品问题 | 全平台复现，或服务端异常 |

**判断要点**：如果**无痕窗口下正常**，问题一定在用户本地缓存/扩展，继续走 L1；如果**无痕窗口也不正常**，才需要升级排查。

---

## 三、先自查服务端

用户反馈「打不开」时，先确认服务是否正常：

```
GET https://euriskotax.zeabur.app/health
→ {"status":"ok","timestamp":"..."}
```

- 返回 `ok` → 服务正常，按客户端问题处理
- 502 / 超时 / 无响应 → **服务端故障**，查部署与日志，不要继续指导用户清缓存

---

## 四、话术库

话术存在服务端 `SupportScript` 表，由管理台「排障」Tab 直接维护（新增 / 编辑 / 删除 / 恢复内置），**改完立即生效，无需发版**。
每条都可一键复制，话术中的 `{RESET_URL}` 会自动替换为当前站点的 `/reset` 链接。

首次部署时，服务启动会把下列 9 条内置话术幂等播种进表（**仅当表为空**，不会覆盖你在后台的编辑）；若被误删，用「恢复内置」即可找回。
下表为速查，详细步骤见管理台。

| 分类 | 典型问题 |
|---|---|
| 缓存 / 版本 | 发版后仍看到旧版页面、功能没更新 |
| 缓存 / 版本 | 登录 / 注册按钮点不动、协议弹窗不出来 |
| 缓存 / 版本 | 页面白屏 / 一直转圈打不开 |
| 缓存 / 版本 | 断网后看到的还是旧内容 / 离线打不开 |
| 账号 / 登录 | 收不到邮箱验证码 |
| 数据 / 同步 | 换设备后看不到云端历史记录 |
| 数据 / 同步 | 计算结果与预期不一致 / 历史记录少了 |
| 权益 / 兑换码 | 兑换码无效 / 专业版没生效 |
| 功能使用 | 如何导出 PDF / 保存计算结果 |

### 通用话术骨架

复制时把 `{}` 内的内容替换为实际情况：

```
你好，这个现象通常是浏览器里的旧缓存造成的。

请按下面两步操作：
1. 打开这个链接（会自动清理旧缓存并回到首页）：
   https://euriskotax.zeabur.app/reset
2. 等页面提示「已完成」后会自动跳转，再试一次刚才的操作。

此操作不会影响你的登录状态和已保存的计算记录。
如果还是不行，麻烦告诉我你用的浏览器和大致时间，我这边继续排查。
```

## 五、高频问题的判断依据

### 1. 兑换码无效 / 专业版没生效

到管理台核对两处：

1. **兑换码页**：目标码是否仍在「可用」列表？若已进「已使用」列表，说明已被消耗（一机一码，用过即失效）。
2. **用户页**：搜索该用户，确认 `plan` 是否为 `pro`、有效期是否正确。

若权益已发但用户看不到 → 让用户走一次 `/reset` 后重新登录（端上权益缓存未刷新）。

### 2. 收不到邮箱验证码

- 频率限制：**5 次 / 15 分钟 / IP**，超限会提示稍后再试
- 让用户查「垃圾邮件 / 广告邮件」并把发件人加入白名单
- 核对邮箱拼写（`.com` / `.cn`、数字与字母混淆）

### 3. 换设备看不到云端历史

两个必要条件：**同一账号** + **专业版权益**。基础版的记录只保存在本机，不跨设备。

### 4. 计算结果和预期不一致

先核对输入项（公积金 / 社保基数有默认值，用户可能未按实际填写），再核对版本号是否为最新，最后才按产品问题上报。

## 六、发版注意事项（给维护者）

> 话术库内容的改动**不需要发版**——在管理台「排障」Tab 直接维护即可（数据存于 `SupportScript` 表）。

版本哨兵依赖两个地方**同时**更新：

| 文件 | 字段 |
|---|---|
| `version.json` | `version` |
| `index.html` | `window.__APP_VERSION__` |

两者不一致会导致**线上用户被误判为旧版**并反复触发自愈重载。发版检查清单：

1. 修改 `index.html` 页面底部展示的版本号
2. 同步 `window.__APP_VERSION__`
3. 同步 `version.json`
4. 确认 `docs/CHANGELOG` 已记录

### 为什么现在基本不会再出现「旧版残留」

| 机制 | 位置 |
|---|---|
| SW 改为 network-first「瘦缓存」，在线永远取网络 | `service-worker.js` |
| 新 SW 激活时清空全部历史缓存 | `service-worker.js` |
| `index.html` / `service-worker.js` / `version.json` 下发 `no-cache` | `server/src/app.js` |
| 注册 SW 时 `updateViaCache: 'none'` + 主动 `reg.update()` | `index.html` |
| 版本哨兵自动自愈 | `index.html` + `version.json` |

### 数据库迁移

本次新增 `SupportScript` 表（迁移 `20260912_add_support_scripts`）：

- 线上：随部署流程的 `prisma migrate deploy` 自动执行，无需人工干预
- 本地：在 `server` 目录执行 `npm run prisma:push:dev` 同步开发库

首次启动时，服务会把内置 9 条话术播种进空表，启动日志可见「排障话术库已内置播种 9 条」。

## 七、升级为产品问题的条件

满足**任意一条**即升级，不要继续让用户清缓存：

- 无痕窗口 / 更换浏览器后**依然复现**
- 服务端 `/health` 异常
- 多个用户在同一时间段反馈同一现象
- 涉及数据丢失、权益错发、金额口径错误

升级时请附上：**用户账号、发生时间、浏览器、复现步骤、截图（含 F12 控制台报错）**。
