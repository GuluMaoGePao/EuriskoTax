## 一、项目价值与意义

### 1.1 对企业的价值

| 价值点 | 说明 | 应用场景 |
|-------|------|---------|
| **年度税费预算** | 预估全年个税支出，用于财务规划和成本控制 | 年度预算编制、人力成本核算 |
| **薪酬结构优化** | 找到税负最优的薪酬区间，避免税率跳档的临界点 | 年终奖发放策略、薪酬调整方案 |
| **人力成本控制** | 精准计算员工实际到手收入与企业成本的关系 | 招聘薪资谈判、薪酬体系设计 |
| **税务合规保障** | 确保薪酬方案符合国家税务政策要求 | 避免税务风险、合规审计 |
| **员工激励设计** | 通过合理的薪酬规划提升员工满意度 | 绩效奖金设计、股权激励方案 |

**企业预算流程**：
```
1. 设定目标税率区间 → 2. 计算所需税前收入 → 3. 规划薪酬结构 → 4. 预估人力成本
```

### 1.2 对个人的价值

| 价值点 | 说明 | 应用场景 |
|-------|------|---------|
| **收入规划** | 提前规划年度收入，优化个人税负 | 年度收入目标设定 |
| **税率区间预判** | 了解不同收入对应的税率，避免税负突变 | 薪资谈判、跳槽决策 |
| **扣除项优化** | 合理利用各项扣除政策，最大化减税收益 | 专项附加扣除申报规划 |
| **年终奖筹划** | 选择最优计税方式（单独/合并） | 年终奖个税优化 |
| **财务目标达成** | 根据税后收入目标反推所需税前收入 | 购房、购车等财务规划 |

**个人规划流程**：
```
1. 设定目标税后收入 → 2. 反推所需税前收入 → 3. 评估可行性 → 4. 调整扣除项
```

### 1.3 预算与汇算的区别

| 维度 | 预算（本工具） | 汇算清缴（税务局） |
|-----|--------------|-------------------|
| **时间** | 事前预估 | 事后结算 |
| **目的** | 规划与预测 | 多退少补 |
| **精度** | 基于预测数据 | 基于实际数据 |
| **适用规则** | 年度税率表和扣除标准 | 预缴规则+年度汇算规则 |
| **结果用途** | 预算编制、决策参考 | 纳税申报、税款结算 |
| **累计减除费用** | 按工作月数计算（6万/年） | 按实际申报月份计算（2026年新规） |

## 二、综合所得计税规则

### 2.1 收入范围及计算方式

| 所得类型 | 收入额计算方式 | 政策依据 |
|---------|--------------|---------|
| **工资薪金所得** | 全部税前收入 | 《个人所得税法》第六条 |
| **劳务报酬所得** | 收入 × (1 - 20%) | 《个人所得税法实施条例》第十四条 |
| **稿酬所得** | 收入 × (1 - 20%) × 70% | 《个人所得税法实施条例》第十四条 |
| **特许权使用费所得** | 收入 × (1 - 20%) | 《个人所得税法实施条例》第十四条 |

**综合所得收入额合计**：
```
综合所得收入额 = 工资薪金 + 劳务报酬×80% + 稿酬×80%×70% + 特许权使用费×80%
```

### 2.4 计算公式

**应纳税所得额**：
```
年度应纳税所得额 = 综合所得收入额 
                  - 60,000元（基本减除费用）
                  - 专项扣除（三险一金）
                  - 专项附加扣除
                  - 其他扣除
                  - 符合条件的公益慈善捐赠
```

**应纳税额**：
```
年度应纳税额 = 年度应纳税所得额 × 适用税率 - 速算扣除数
```

**税后收入**：
```
年度税后收入 = 年度累计税前收入 - 年度应纳税额
```

### 3.4 税收优惠（2023-2027年）

**减半征收优惠**：
- **适用对象**：个体工商户、个人独资企业、合伙企业
- **优惠内容**：年应纳税所得额不超过2,000,000元的部分减半征收
- **政策依据**：财政部公告2023年第6号

**计算公式**：
```
减免税额 = min(应纳税所得额, 2,000,000) × 适用税率 × 50%
实际应纳税额 = 应纳税额 - 减免税额
```

### 3.5 计算公式

**应纳税所得额**：
```
应纳税所得额 = 收入总额 - 成本 - 费用 - 税金 - 损失 - 其他支出 - 允许弥补的以前年度亏损
```

**应纳税额（未减半）**：
```
应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数
```

**实际应纳税额**：
```
实际应纳税额 = 应纳税额 - 减免税额
```

```
应纳税额 = 应纳税所得额 × 20%
```

**偶然所得**：
```
应纳税额 = 每次收入额 × 20%
```

## 五、反向倒算规则

### 5.1 全部模式与单个模式

反向倒算功能支持两种显示模式：

**全部模式**：
- 同时计算并展示三种计算模式（保守、均衡、进取模式）的结果
- 在对比表格中显示所有关键指标：年度应纳税所得额、年度税前收入、全年应缴税额、年度税后收入
- 底部展示三种模式的详细预算表，每个模式独立显示
- 适合对比分析不同模式的税负差异

**单个模式**：
- 仅计算并展示所选单一模式的结果
- 显示年度应纳税所得额、年度税前收入、全年应缴税额
- 展示单个模式的详细预算表
- 适合针对特定模式的深入规划

### 5.2 按目标税率倒算

**核心逻辑**：
1. 根据目标税率确定对应的应纳税所得额范围 `[min, max]`
2. 根据选择的计算模式确定应纳税所得额基准值
3. 税前收入 = 应纳税所得额 + 扣除总额
4. 计算税额和税后收入

**计算模式**：

| 模式 | 计算基准 | 适用场景 | 示例（20%税率档） |
|------|---------|---------|------------------|
| **🌱 保守模式** | 最低值+1 | 稳健型收入规划，了解达到目标税率的最低门槛 | 144,001元 |
| **⚖️ 均衡模式** | 区间中间值 | 常规收入预算，反映区间内平均税负水平 | 222,000元 |
| **🚀 进取模式** | 最高值 | 积极型收入规划，接近区间上限的税负水平 | 300,000元 |

**模式说明**：
- **保守模式**：计算达到目标税率的最低收入门槛，适合稳健型收入规划，确保收入刚好达到目标税率级别。最低档位（3%）设置12,000元/年作为合理基准。
- **均衡模式**：使用税率档位中间值计算，反映区间内的平均税负水平，适合常规收入预算规划。
- **进取模式**：接近税率档位上限计算，反映较高收入水平的税负情况，适合积极型收入增长规划。

**取整规则**：

| 模式 | 有限档位计算 | 最高档位（无上限）计算 | 说明 |
|------|------------|---------------------|------|
| **🌱 保守模式** | `max(最低值 + 1, 最低档位最低值)` | `min + 1` 或 `minimumTaxableIncome` | 稳健型规划，最低收入门槛 |
| **⚖️ 均衡模式** | `(最低值 + 最高值) / 2` | `min + 100,000` | 常规预算，中间水平 |
| **🚀 进取模式** | `最高值` | `min + 200,000` | 积极规划，较高收入水平 |

**边界保护**：应纳税所得额始终 ≥ 0，避免负数或极小值

**档位最低合理值（预算场景优化）**：

| 档位类型 | 最低合理应纳税所得额 | 说明 |
|---------|---------------------|------|
| 最低档位（min=0） | 12,000元/年 | 相当于每月1,000元，合理的低收入基准，避免1元等不合理数值 |
| 其他档位 | 使用原值+1 | 已有合理基数，保持精确性和适用性 |

**边界处理**：
- 仅对最低税率档位设置最低值（12,000元/年），其他档位保持原值+1
- 确保涵盖所有收入群体，包括低收入目标群体
- 自动确保应纳税所得额非负，防止扣除总额大于税前收入导致负数
- 这样设置既避免了不合理的小额应纳税所得额，又保持了对所有收入群体的适用性

**适用场景**：规划收入目标，了解不同税率档位对应的收入水平

**计算公式**：
```
应纳税所得额 = 根据计算模式确定的基准值
税前收入 = 应纳税所得额 + 扣除总额
税额 = 应纳税所得额 × 税率 - 速算扣除数
税后收入 = 税前收入 - 税额
```

**代码实现**（`js/tax-calculator.js` 第785-889行 `calculateFromTargetRate` 函数）

### 5.2 按月度税后收入倒算

**核心逻辑**：
1. 年度税后收入目标 = 月度税后收入 × 工作月数
2. 使用二分法求解税前收入
3. 迭代公式：`税前收入 = 税后收入 + 应纳税额`

**适用场景**：已知期望到手收入，反推所需税前收入

**代码实现**（`js/tax-calculator.js` 第650-718行 `calculateFromMonthlyNet` 函数）

### 5.3 按目标税额倒算

**核心逻辑**：
1. 已知税额，反推应纳税所得额
2. 税前收入 = 应纳税所得额 + 扣除总额

**适用场景**：税务筹划，控制税负水平

**代码实现**（`js/tax-calculator.js` 第724-810行 `calculateFromTargetTax` 函数）

## 六、税收优惠与特殊规则

### 6.1 公益慈善捐赠

**规则**：
- 个人将所得对教育、扶贫、济困等公益慈善事业捐赠
- 捐赠额未超过应纳税所得额30%的部分可扣除
- 国务院规定全额扣除的，从其规定

**计算公式**：
```
可扣除捐赠额 = min(实际捐赠额, 应纳税所得额 × 30%)
```

**政策依据**：《个人所得税法》第六条

### 6.2 年终奖计税选择

**规则**：
- **单独计税**：年终奖 ÷ 12确定税率，税额 = 年终奖 × 税率 - 速算扣除数
- **合并计税**：与工资薪金合并，按综合所得税率计算

**选择建议**：
- 年收入10万元以下：建议合并计税
- 年收入20万元以上：建议单独计税

**政策依据**：财政部公告2023年第28号

**代码实现**（`js/tax-calculator.js` 第187-197行 `calculateBonusTax` 函数）

### 6.3 预缴规则说明（预算场景适用性）

| 规则 | 对预算的影响 | 预算场景适用性 |
|-----|-------------|--------------|
| **累计减除费用新规（2026年4月）** | 影响月度预缴，不影响年度预算 | 不需要实现 |
| **一次性扣除6万元** | 影响特定人群预缴，不影响年度预算 | 不需要实现 |
| **平台从业人员劳务报酬** | 影响特定行业预缴，年度预算影响有限 | 不需要实现 |

> **预算场景说明**：本工具用于年度预算规划，基于年度税率表计算，不受月度预缴规则影响。实际预缴时可能存在差异，但年度汇算时会统一清算。

### 7.1 办理时间

| 情形 | 条件 | 政策依据 |
|-----|------|---------|

### 7.3 计算公式

```
应退/应补税额 = [(综合所得收入额 - 60,000元 - 专项扣除 - 专项附加扣除 - 其他扣除 - 捐赠) × 适用税率 - 速算扣除数] - 减免税额 - 已预缴税额
```
