## 2. 第 0 周点火清单（逐日，全部为执行动作）

| 天 | 动作 | 交付标准 | 备注 |
|---|---|---|---|
| D1 | 查 `euriskotax.com` 可用性 → 腾讯云注册 | 域名在手；**同时注册 `.cn` 并 301 指向主域** | 所有者必须填公司全称 |
| D1 | 生成企业微信「联系我」活码 → 填入 `index.html` | 留资弹窗出现活码 | 活码可带 `state` 参数做入口归因 |
| D2 | 腾讯云账号企业实名 + 购买大陆地域轻量服务器 | 备案资源校验通过 | 有效期 ≥3 个月 |
| D3 | 备齐材料并提交 ICP 备案 | 订单进入管局队列 | 网站名称一次定死（≥3 字、非纯英文，推荐公司全称/简称） |
| D3 | 定顾问值班表 | 响应时限 ≤2 小时 | 线索不隔夜 |
| D3 | 生成首批邀请码 | 管理台「邀请码」Tab 可见 | 记录发放对象，便于回访 |
| D4–D5 | 邀请 5–10 名种子用户（私聊话术见文案库） | 每人完成一次"用真实工资单核验" | 优先近半年跳槽/谈薪、有副业或租金收入的人 |
| D6–D7 | 修种子用户反馈的高优 bug | 高优 bug 清零 | 发帖前的稳定性检查 |

**D1 之后的等待项（不可压缩）**：域名实名认证后须满 **3 个自然日**才能提交备案（非腾讯云注册的域名满 3 个工作日）。

## 4. 指标看板与埋点

### 4.1 北极星

> **`lead_submit / calc_done`** —— 算完之后有多少人愿意留下联系方式。
> 它同时度量了"流量是否对口"和"结果页说服力"，且不受注册摩擦干扰。

### 4.2 五步漏斗（已埋点，无需开发）

| 步骤 | 事件 | 含义 |
|---|---|---|
| 1 | `visit` | 访问 |
| 2 | `calc_done` | 算完（**游客也算**，口径已修正为全量） |
| 3 | `save` | 保存到历史（登录行为） |
| 4 | `share` | 生成分享图 |
| 5 | `lead_click` | 点击服务引导（唯一入口已包装） |

### 4.3 每日观察（建议固定时间，1 分钟）

- 管理台 →「转化漏斗」区块：各步转化率 + 北极星
- 管理台 →「线索」Tab：新线索、待分配、状态分布
- 接口快照（含日粒度趋势）：

```powershell
curl.exe -s https://euriskotax.zeabur.app/api/stats/overview -H "X-Admin-Token: <ADMIN_TOKEN_PROD>"
```

关注字段：`users.newToday`（发帖脉冲）、`calculations.byType`（comprehensive / business / classification / reverse → 决定下一个 SEO 页写哪个词）、`dailyTrend`（7 日留存趋势）。

> ⚠️ 常见误读：埋点与计算统计**只在用户点击「保存」时触发**，注册后只浏览不保存不会产生记录 —— 数字为 0 不等于没人访问。

### 4.4 每周复盘三问

1. 本周**线索量**是多少？有效线索占比多少？（质量）
2. 本周**成交**几单、客单价多少？（变现）
3. 哪个渠道贡献的线索最多、质量最好？（渠道 ROI → 下周加码哪个）

## 5. 线索跟进 SOP

### 5.1 状态机（管理台已支持行内修改）

`new`（新线索）→ `contacted`（已联系）→ `qualified`（有明确需求）→ `converted`（已成交）／ `dropped`（无效）

**纪律**：状态必须当天更新。状态长期停留在 `new` 的线索，等于没有线索。

### 5.2 跟进节奏

| 时限 | 动作 |
|---|---|
| ≤2 小时 | 首次触达（企微/电话），确认需求与主体类型 |
| ≤24 小时 | 给出明确下一步（报价单 / 需要补充的信息 / 明确不合适） |
| 3 天 | 未回复则二次触达 |
| 7 天 | 转 `dropped` 并记录原因（原因是最有价值的复盘素材） |

### 5.3 留资字段的用法（这是我们的信息优势）

| 字段 | 顾问怎么用 |
|---|---|
| **省 · 市** | 判断适用当地的社保/公积金口径（计算页按全国口径，差异由顾问核对）—— 也是分派依据（按省收敛比按市翻页快） |
| **场景（scene）** | 经营所得 / 汇算清缴 / 预算表 → 决定开场话术与推荐服务 |
| **来源（source）** | `result_business` / `result_settlement` / `result_budget` / `profile` / `home_banner` / `modal` / `share` → 用于渠道 ROI 复盘 |
| **备注** | 用户自述需求，优先读这一栏 |

### 5.4 合规红线

- 全程禁用"避税 / 节税 / 税筹"等表述，统一用"申报核对 / 汇算清缴代办"
- 留资含收入相关敏感信息：提交时已做显式同意与留痕，**不得用于服务跟进之外的用途**
- 不做申报承诺，不做结果保证；服务交付按公司既有合规流程执行

## 7. 单位经济学实测口径（用来替换企划书里的假设）

### 7.1 计算链

```
月访问量          ← 待接入统计（当前只有计算与线索侧数据）
  × visit→calc_done 率
  = calc_done
  × lead_click 率
  = lead_click
  × click→submit 率
  = 留资数（lead_submit）
  × 有效线索率（不含误触/学生/无关咨询）
  = 有效线索
  × 成交率
  = 成交单数
  × 客单价
  = 月收入
```

### 7.2 待填字段（前 30 天积累，30 天后回填企划书）

| 字段 | 当前 | 数据来源 |
|---|---|---|
| 月访问量 | 无（未推广） | 需补一个访问统计（可与 `visit` 漏斗事件对齐） |
| `visit → calc_done` | 待测 | `/api/admin/leads/funnel` |
| `calc_done → lead_click` | 待测 | 同上 |
| `lead_click → lead_submit` | 待测 | 同上 |
| 有效线索率 | 待测 | 管理台线索状态机（`qualified` / 总数） |
| 成交率 | 待测 | `converted` / 有效线索 |
| 客单价 | 待测 | 人工台账（§6 第 6 项） |

### 7.3 校准节奏

- **第 30 天**：首次回填，替换企划书第八章的假设值
- **第 90 天**：判断"服务成交"这条主线是否成立 —— 若成交率为 0，问题通常在**线索质量或顾问承接**，不是流量不够
- **口径纪律**：所有对外引用的数字必须来自实跑/实测，不得用"基线 + 新增"推算（项目已有此教训）

## 8. 与开发阶段的并行关系（弹药节奏）

| 开发阶段 | 商业角色 | 何时做 |
|---|---|---|
| 阶段15A 个税纵深（劳务报酬/股权激励/离职补偿…） | **获客弹药**（每个税种一批关键词） | W3 起，与运营并行 |
| 阶段15B 企业税种（增值税/企业所得税/附加税费/印花税） | 弹药 + **B 端 API 前置**（没有企业税种无货可卖） | 15A 之后 |
| 阶段15C 社保/薪酬（社保基数 / 税后工资落地页） | **收编阶段14 遗留待办**，3–5 天可交 | W4 起 |
| 阶段15D 架构守护（税种注册表 / 多税种版本化 / 落地页矩阵） | 让"一税种一页"可持续复制 | 横切 |
| 阶段16A/16B/16C（境内节点 / 官方支付 / 微信小程序） | **解锁收款与扩面** | 备案通过后 |
| 阶段16D B 端 API | 第二增长曲线 | 15B + 备案之后 |

**一句话**：阶段15 的商业本质不是"功能更多"，而是**买关键词 + 铺 B 端货架**。
