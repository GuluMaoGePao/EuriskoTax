# 个人所得税计算系统

基于2026年最新个人所得税计算规则设计的专业税务计算工具，支持综合所得、经营所得、分类所得的全方位计算，以及创新的反向倒算功能。

## 功能特点

### 1. 全面的所得类型覆盖

| 所得类型 | 计税方式 | 适用人群 |
|---------|---------|---------|
| 综合所得 | 超额累进税率(3%-45%) | 工资薪金、劳务报酬、稿酬、特许权使用费 |
| 经营所得 | 超额累进税率(5%-35%) | 个体工商户、个人独资企业、合伙企业 |
| 分类所得 | 比例税率(20%) | 利息股息、财产租赁、财产转让、偶然所得 |

### 2. 智能计算引擎

- **实时计算**：输入即计算，无需等待
- **精准算法**：二分法精确计算，支持小数精度到分
- **政策适配**：自动应用最新税收优惠政策
- **多模式支持**：正向计税 + 反向倒算

### 3. 专业扣除体系

```

├── 基本减除费用（60,000元/年）

│   ├── 养老保险

│   ├── 失业保险
│   └── 住房公积金
├── 专项附加扣除
│   ├── 子女教育（3岁以下婴幼儿照护）
│   ├── 赡养老人
│   ├── 住房租金
│   ├── 住房贷款利息
│   ├── 继续教育

└── 其他扣除
    ├── 个人养老金
    ├── 税延型养老保险
    └── 商业健康保险
```

## 计税方式详解

### 综合所得计算

**收入组成**：
```
综合所得 = 工资薪金 + 劳务报酬×80% + 稿酬×80%×70% + 特许权使用费×80%
```

**年终奖处理**：
- 单独计税：除以12后确定税率，税额 = 年终奖 × 税率 - 速算扣除数
- 并入综合所得：与工资薪金合并计税

**适用税率表**：

| 级数 | 应纳税所得额 | 税率 | 速算扣除数 |
|------|-------------|------|-----------|
| 1 | ≤36,000 | 3% | 0 |
| 2 | 36,000-144,000 | 10% | 2,520 |
| 3 | 144,000-300,000 | 20% | 16,920 |
| 4 | 300,000-420,000 | 25% | 31,920 |
| 5 | 420,000-660,000 | 30% | 52,920 |
| 6 | 660,000-960,000 | 35% | 85,920 |
| 7 | >960,000 | 45% | 181,920 |

**计算公式**：
```
应纳税额 = 应纳税所得额 × 适用税率 - 速算扣除数
```

### 经营所得计算

**收入组成**：
```
经营所得 = 经营收入 - 成本 - 费用 - 投资者减除费用 - 其他扣除
```

**减半征收政策**：
- 适用对象：年应纳税所得额≤2,000,000元的部分
- 优惠力度：减按50%计入应纳税所得额
- 适用期限：2023年1月1日至2027年12月31日

**适用税率表**：

| 级数 | 应纳税所得额 | 税率 | 速算扣除数 |
|------|-------------|------|-----------|
| 1 | ≤30,000 | 5% | 0 |
| 2 | 30,000-90,000 | 10% | 1,500 |
| 3 | 90,000-300,000 | 20% | 10,500 |
| 4 | 300,000-500,000 | 30% | 40,500 |
| 5 | >500,000 | 35% | 65,500 |

### 分类所得计算

**所得类型**：

| 类型 | 收入类型 | 计税方式 |
|------|---------|---------|
| 利息、股息、红利所得 | 利息、股息、红利 | 全额计税 |
| 财产租赁所得 | 租赁收入 | ≤4000：减800；>4000：减20% |
| 财产转让所得 | 转让收入 | 减除财产原值和合理费用 |
| 偶然所得 | 奖金、奖品等 | 全额计税 |

**统一税率**：20%

## 反向倒算功能

本系统的核心创新功能，支持三种反向倒算模式和两种显示模式：

### 显示模式

**全部模式**：
- 同时展示三种计算模式（保守、均衡、进取）的完整结果
- 上方显示对比表格：年度应纳税所得额、年度税前收入、全年应缴税额、年度税后收入
- 下方展示三种模式的详细预算表，每个模式独立完整显示
- 适合对比分析不同模式的税负差异

**单个模式**：
- 仅显示所选单一模式的结果
- 显示年度应纳税所得额、年度税前收入、全年应缴税额
- 展示单个模式的详细预算表
- 适合针对特定模式的深入规划

### 1. 按目标税率倒算

**功能**：给定目标税率，计算达到该税率所需的收入范围

**应用场景**：
- 了解不同税率档位对应的收入区间
- 规划收入结构，控制税负
- 评估薪资调整后的税负变化

**输出**：
- 最小税前收入（进入该税率档位）
- 最大税前收入（不超出该税率档位）
- 对应的到手收入区间

### 2. 按月度税后收入倒算

**功能**：给定目标月度税后收入，精确计算所需税前收入

**算法**：二分法精确搜索，精度达0.01元

**应用场景**：
- 设定明确的到手收入目标
- 反推需要的税前工资
- 薪资谈判参考

**输出**：
- 精确税前收入
- 对应的税额
- 适用的税率

### 3. 按目标税额倒算

**功能**：给定目标税额（或税额+到手金额组合），计算所需税前收入

**两种模式**：
- 仅输入目标税额：计算达到该税额的税前收入
- 同时输入税额+到手金额：验证组合合理性并计算

**应用场景**：
- 设定具体的纳税金额目标
- 合理的税负规划
- 年终奖发放策略参考

**输出**：
- 精确税前收入
- 实际到手金额
- 实际税率

## 操作指南

### 首次使用

1. 打开系统，进入首页
2. 选择需要的计税模式（综合所得/经营所得/分类所得/反向倒算）
3. 按照指引填写相关信息
4. 系统自动计算并显示结果
5. 可选择保存、导出或打印

### 综合所得计算流程

```
步骤1：填写基本信息
    ├── 工作月数（1-12个月）
    ├── 基本减除费用（默认60000元）
    └── 是否有综合所得（影响经营所得减除费用）

步骤2：输入收入明细
    ├── 工资薪金（月度）
    ├── 劳务报酬（年度）
    ├── 稿酬所得（年度）
    ├── 特许权使用费（年度）
    └── 年终奖（年度）

步骤3：填写扣除项
    ├── 专项扣除（社保、公积金）
    ├── 专项附加扣除
    └── 其他扣除（个人养老金等）

步骤4：查看结果
    ├── 税额计算明细
    ├── 税后收入
    └── 月度预算表
```

### 经营所得计算流程

```
步骤1：填写收入与成本
    ├── 经营收入
    ├── 成本
    └── 费用

步骤2：填写扣除项
    ├── 投资者减除费用
    └── 其他扣除

步骤3：设置参数
    ├── 是否已有综合所得
    └── 已预缴税额

步骤4：查看结果
    ├── 应纳税额（含减半优惠）
    ├── 减半征收减免税额
    └── 应补/应退税额
```

### 反向倒算流程

```
步骤1：选择倒算方式
    ├── 按目标税率倒算
    ├── 按月度税后收入倒算
    └── 按目标税额倒算

步骤2：选择显示模式
    ├── 全部模式：同时展示三种模式的完整结果
    └── 单个模式：仅展示所选模式的结果

步骤3：输入目标值
    └── 根据选择的倒算方式输入相应目标

步骤4：填写扣除项
    └── 与正向计算相同

步骤5：计算并查看
    ├── 反推的税前收入
    ├── 对应的税额和到手收入
    └── 月度预算表（全部模式展示三种，单个模式展示一种）
```

### 预算表说明

**预算表用途**：展示全年12个月的预计税负分布，用于年度财务规划和参考

**累计应缴**：到该月为止累计应该缴纳的预计税额

**累计预缴税额**：全年累计应该预缴的预计税额（计算得出，非实际缴纳记录）

**应退/补税额**：年度应纳税额 - 累计预缴税额（预算估算）

**注意**：用户实际缴纳记录需到个人所得税APP或电子税务局查询

## 数据管理

### 保存计算结果

- 点击「保存计算结果」按钮
- 系统自动保存到本地历史记录
- 支持跨会话数据持久化

### 查看历史记录

- 点击「历史记录」查看所有保存的计算
- 支持按类型筛选（综合/经营/分类/反向）
- 可单独查看或删除记录

### 数据存储

- 使用浏览器 localStorage 存储
- 最大保存50条记录
- 自动清理过期数据
