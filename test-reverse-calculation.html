反向倒算功能测试

测试用例 1: 从税额倒算（综合所得）

输入：税额 = 3600, 工作月数 = 12, 基本扣除 = 5000/月

预期结果：税前收入 = 126000 (36000应纳税所得额 + 60000基本扣除 + 30000专项扣除)

测试用例 2: 从税后收入倒算（综合所得）

输入：税后收入 = 122400, 工作月数 = 12, 基本扣除 = 5000/月

预期结果：税前收入 = 126000 (税额 = 3600)

测试用例 3: 从税额倒算（经营所得）

输入：税额 = 1500, 工作月数 = 12

预期结果：应纳税所得额 = 30000 (税率 5%)

测试用例 4: 从税后收入倒算（经营所得）

输入：税后收入 = 28500, 工作月数 = 12

预期结果：应纳税所得额 = 30000 (税额 = 1500)
