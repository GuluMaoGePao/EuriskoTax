使用帮助

了解如何使用本工具

正向计税

输入您的收入和扣除项信息，系统将自动计算年度个人所得税，并生成标准化年度个税预算表。

反向倒算

输入税额信息和扣除项，系统将自动反推税前收入，适用于财务人员和薪酬规划。

经营所得计税

适用于个体工商户、个人独资企业、合伙企业投资者，支持成本、费用等扣除项。

分类所得计税

适用于利息、股息、红利所得、财产租赁、转让所得及偶然所得的计税计算。

数据保存

您可以保存计算结果，以便后续查看和比较。所有数据仅保存在本地，不会上传至服务器。

数据导出

支持将计算历史导出为JSON或CSV格式，方便数据备份和迁移。

PDF导出

计算完成后，您可以将预算表导出为PDF格式，方便打印和保存。

计税规则依据

本小程序根据2026年个人所得税计算规则手册设计，确保计算结果准确无误。

个税免征特殊规则

  • 福利彩票、体育彩票单次中奖收入≤10000元（含1万元），免征个人所得税
  • 餐饮发票等单张发票奖金≤800元，免征个人所得税
  • 仅大病医疗个人负担累计超过15000元的部分，可纳入扣除范围，年度扣除上限80000元

汇算清缴时间

  • 综合所得年度汇算清缴：次年3月1日至6月30日
  • 经营所得年度汇算清缴：次年1月1日至3月31日

专项附加扣除

专项附加扣除需在个人所得税APP中据实填报，留存相关佐证材料备查。

汇算差异说明

劳务报酬、稿酬、特许权使用费预缴时按固定税率计税，年度汇算时并入综合所得，通常会产生税额差额，需通过汇算多退少补。

预算与实际差异

  • 本工具为年度预算规划工具，计算结果基于年度税率表
  • 实际月度预缴可能因累计减除费用新规产生差异
  • 预算结果仅供参考，实际应纳税额以年度汇算清缴结果为准

常见问题

体验版和专业版有什么区别？

体验版即限时（14 天）专业版，功能完全一致。正式专业版支持兑换码开通（线下购买后发放，见上方输入框），线上购买通道后续开放；体验期间同步的数据会完整保留。

体验到期后，我的数据会丢失吗？

不会。云同步记录按账号归属云端，到期仅是停用同步能力；本地历史不受影响，再次领取体验或升级正式版后即可继续同步取回。

政策要点和更新公告需要专业版吗？

不需要，未登录也能看。计税能力、社保口径、政策要点与更新公告对所有用户开放；专业版解锁的是云增值能力（多设备同步、完整 PDF 报告、更大的方案对比库）。

如何升级到正式专业版？

隐私政策

本应用高度重视您的个人隐私，遵循《中华人民共和国个人信息保护法》相关规定。

一、信息收集

1. 注册信息：邮箱（用于登录和验证码）、用户名、密码（加密存储）、手机号（选填）。

2. 使用数据：您的计算记录默认仅保存在浏览器本地（localStorage），支持离线使用与本地历史查询，本应用不会自动将计算记录上传至服务器。登录状态下，为改进产品体验，我们会匿名记录您使用的计算功能类型与次数（例如"综合所得 / 经营所得 / 反向倒算"），不含任何收入、扣除额等具体输入数据，且不与您的账号画像关联。

3. 填写草稿：多步计税过程中已填写的内容（含月收入、各项扣除等）会自动暂存为本地草稿，仅供您下一次进入同一流程时接着填写；草稿仅保存在您本机浏览器（localStorage），不会上传服务器，也不会进入云同步，距上次填写超过 7 天自动清除。您可在页面顶部的草稿提示条上一键「清除重填」，退出登录时草稿随本地数据一并清除。

4. 本应用不收集您的位置信息、设备标识或其他敏感个人信息。

二、信息使用

1. 注册信息仅用于账号管理和身份验证。

2. 计算记录仅用于在本地为您提供历史查询功能；匿名使用统计（计算类型/次数）仅用于产品功能优化，不涉及您的具体计税输入内容。

3. 本应用不会将您的个人信息出售、出租或提供给任何第三方。

三、信息存储与安全

1. 密码使用 bcrypt 加密存储，不可逆向解密。

2. JWT Token 用于会话管理，有过期机制。

3. 数据库采用加密连接，部署在可信云平台。

四、信息删除与账号注销

您有权删除您的账号及相关数据。登录后进入"个人中心 → 账户设置 → 注销账号"即可自助注销（需邮箱确认），注销后账号与数据将被永久删除。如需帮助，请联系开发者。

五、Cookie 与本地存储

本应用使用 localStorage / sessionStorage 存储登录状态（是否勾选"保持登录状态"决定登录有效期）和税务档案等偏好设置，不使用跟踪 Cookie。清除浏览器数据不会影响服务器端数据。

六、未成年人保护

本应用面向个人税务计算需求，不建议未成年人使用。如发现未成年人注册账号，我们将予以注销。
